# Architecture Decision Records

This directory contains the accepted architecture decisions for the predictive reliability platform. ADRs are numbered in dependency order and preserve the original topic mapping. Each record states the decision, alternatives, consequences, explicit non-goals, and measurable verification/exit criteria.
